# own list) instead of this file. Names here are still validated against
# that list.

# Format, one line per pyperformance TASK:
#
#   task: result_name [result_name ...]
#
# The left column is what `pyperformance run --benchmarks` selects and is
# validated against the provisioned tool's own list by the self-tests.
# The right column is the EXACT set of result names that task must report
# under the pinned pyperformance: the two namespaces differ -- a task may
# emit several results (scimark emits scimark_sor, scimark_fft, ... and
# never one under its own name).  The completeness judge requires the
# reported result-name set to equal the union of the right column exactly,
# so a task that silently stops reporting -- or a tool upgrade that
# renames or adds results -- is a manifest edit, never an accident.
